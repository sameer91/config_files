*** Regular Expressions
need to use backspash '\' for meta characters otherwise they are
treated as literal characters.
| Constructs | Description                                          |   |
|------------+------------------------------------------------------+---|
| \\vert     | Alternative                                          |   |
| \(,\)      | Capturing group                                      |   |
| \{,\}      | Repetition                                           |   |
| \<,\>      | begin/end of word                                    |   |
| \_<,\_>    | begin/end of symbols                                 |   |
| \scode     | matches any char whose syntax table code is code     |   |
| \Scode     | matches any char whose syntax table code is  notcode |   |

Syntax classes:
  - whitespace char (-): whitespace, newlines
  - word constitutes (w): upper and lower case char
  - symbol constitues (_): all word constitutes and symbols
  - punctuation char (.): characters like . ;
  - open/close parenthesis ('(' and ')'): characters that form a
    grouped pair i.e. (), [], {}, <>
  - string characters ("): includes character that mark a string
    i.e. double and single quotes
  - open/close comment (<,>): any character that defines the boundary
    of a comment.

 note: c-u m-x what-curson-position or c-u c-x = to see character
 class at point.

 | consructs | desc                               |
 |-----------+------------------------------------|
 | \1 to \9  | inseart text from grou \n          |
 | \?        | prompts for text input from user   |
 | \#        | insers a number inscrmented from 0 |
 | \&        | inseart whole match string         |
